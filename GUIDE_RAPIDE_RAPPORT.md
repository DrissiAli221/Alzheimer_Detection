# 🚀 Guide Rapide - Génération de Rapports PDF

## En 4 Étapes Simples

### 1️⃣ Analyser un Scan IRM
```
Onglet "Analyze" → Upload Image → Attendre l'analyse
```

### 2️⃣ Remplir les Infos Patient (Optionnel)
```
Cliquer sur "📋 Enter Patient Information"
→ Remplir le formulaire
→ Fermer l'expander
```

### 3️⃣ Générer le Rapport
```
Cliquer sur "📄 Generate Report"
→ Attendre 2-3 secondes
→ Message de succès ✅
```

### 4️⃣ Consulter ou Télécharger
```
Option A: "👁️ View Report" → Voir dans l'app
Option B: "⬇️ Download PDF" → Télécharger le fichier
```

## 💡 Astuces

### Pour un Rapport Complet
- Remplissez TOUTES les informations du patient
- Ajoutez des notes médicales pertinentes
- Vérifiez la date du scan

### Pour un Rapport Rapide
- Laissez les champs vides
- Le système génère automatiquement :
  - ID patient : AUTO-[timestamp]
  - Nom : "Not Provided"
  - Date : Date actuelle

## 📋 Contenu du Rapport

✅ En-tête avec logo et titre  
✅ Informations du rapport (ID, date, méthode)  
✅ Données du patient  
✅ Résultat de l'analyse (coloré selon la sévérité)  
✅ Tableau des probabilités  
✅ Image du scan IRM  
✅ Interprétation clinique détaillée  
✅ Recommandations médicales  
✅ Disclaimer important  
✅ Informations du médecin

## 📞 Besoin d'Aide ?

**Problème :** Bouton "Generate Report" ne fonctionne pas  
**Solution :** Vérifiez que l'analyse est terminée

**Problème :** PDF ne se télécharge pas  
**Solution :** Vérifiez les paramètres de votre navigateur

**Problème :** Aperçu ne s'affiche pas  
**Solution :** Utilisez "Download PDF" à la place
